# 简历设计 / jianli

为任何行业设计有辨识度、适合岗位且易于阅读的简历。设计应来自求职者、岗位和投递情境；既不是统一模板换色，也不是用装饰盖住履历。整理内容和制作视觉同样重要。适用范围可包括首次制作、重设计或局部修改；已确定的方向和用户对工作范围的明确要求优先，不对局部修改重走完整流程。

## 1. 了解人与场景

了解求职岗位、行业、投递方式、语言、履历、个人偏好和交付格式；利用用户已提供的信息，集中询问影响设计的缺口。使用者可以是求职者本人，也可以代他人制作。无真实资料时允许用显著标注的虚构内容、概念图片做视觉探索，但不可作为真实履历或候选人作品；正式投递前以真实资料替换并核对。

梳理岗位所需信息并优化语言：在真实资料内提炼职责、行动和成果，缺少数据不捏造；保留原稿并说明有意义的删改。联系信息、教育、经历及相关能力应能被快速找到，具体内容依岗位和个人情况取舍。

## 2. 研究与讨论：先于草图

结合岗位、目标地区和投递渠道研究行业视觉语言、实际设计案例和招聘要求。搜索发现案例后打开原始页面并实际查看图像；展示可访问的原始链接和具体画面，区分简历、作品集、海报及转载。参考只用于学习结构、层次和审美原则；未经许可不复制作品或冒充候选人素材。若不能实际查看，明确说明限制，不把搜索摘要称作已查看。

需要梳理国内求职建议时，参考 [招聘研究](references/招聘研究.md)，再按具体岗位和时间核验。区分三类：招聘方或投递渠道明确要求；真实、可读、事实可核对等实践原则；单页、照片、颜色、字体等依地区、岗位和个人条件调整的常见建议。国内普通求职优先探索单页，招聘要求、资历与内容量可能需要其他形式，不要把单页当成普遍法规。敏感个人信息按用途和用户选择判断，不默认要求身份证号、住址或照片；不擅自上传个人资料。

基于看过的参考，向用户提出多个气质明显不同且适合其行业和个人的方向。比较构图、信息结构、配色、字体、图文关系、适用情境及取舍，说明各自借鉴的原则；不要把换颜色称为不同方向。先和用户讨论，明确草图探索方向再制作。尊重用户明确要求的工作阶段；仅研究或分析时不擅自生成草图。

## 3. 多张视觉草图与确认

按讨论结果制作并展示多张真实可查看的整页视觉草图：页面结构、主要信息区、配色和气质清晰；文字可简化或模糊，明确其非正式履历。草图之间应有实质设计差异，允许大胆但符合目标行业的表达。没有可用的视觉制作能力时，说明缺口，不用文字方案、空白占位框或模板伪称草图。

用户可选择一个方向精修，也可组合不同稿的版式、配色等；判断组合是否协调并展示修改稿。**只有用户确认草图后才开始正式制作。** 同一会话内已明确确认的方向继续有效；局部修改直接按用户要求进行，不重复要求确认。

## 4. 制作与交付

以确认草图为视觉基准，尽可能还原构图、层次、色彩、图文关系和整体气质，把草图文字替换为经核实的真实内容。必要时调整内容密度和字号以保证可读性；如草图、内容量或可编辑格式之间有实质冲突，说明具体差异并与用户讨论。未经用户提供的作品不冒充本人作品。保证文档文字尽可能可选择、可复制，并按目标渠道核查必要格式；不保证所有招聘系统都能正确解析复杂排版。

按用户和实际环境选择可编辑文件，例如 Figma 原生对象或 Word 文档，并提供投递用 PDF。确认工具和字体实际可用；重要文字应是真实文本而非整页图片。对于要求 Figma 或 Word 的任务，不能将 HTML、图片或改后缀的文件冒充其原生可编辑文件；有能力缺口时说明能提供什么和未实现什么。跨环境使用时根据可用工具与本地规则选择制作和视觉研究方法，不依赖特定用户名、机器路径、私有工具或固定服务商。

检查真实导出文件：事实、日期、联系方式、作品来源、页数、字体、文字可读性和可编辑性、断行与边界、链接，以及与确认草图的视觉一致性。打开并观察实际导出页，发现问题修正复检；机械检查不能替代视觉判断。正式稿缺少真实事实时只能称探索稿，不能称可投递成品。交付可查看的预览、PDF 和可编辑文件，并说明编辑边界和未完成项。
