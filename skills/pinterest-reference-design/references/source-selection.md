# 按设计问题选择参考

下表是检索起点，不代表已浏览、当前可访问、免费或获准复用。根据任务选有价值的渠道，不强行访问全部网站或凑固定数量。

| 设计问题 | 可选来源 | 需要查看的证据 |
|---|---|---|
| 真实业务语境与叙事 | 企业/银行投资者关系页面、业绩发布材料、公开年报、咨询机构公开报告、Speaker Deck | 完整页面、结论与证据关系、来源注释、复杂页及章节节奏；不能只看封面 |
| 信息密度与排版 | Behance 完整演示/编辑设计项目、站酷、花瓣、Pinterest、设计工作室案例、公开杂志/报告 | 匹配内容量的长文、表格、流程内页，字形对比、阅读路径、网格和留白 |
| 数据与流程表达 | FT Visual Vocabulary、Datawrapper 官方示例与教程、IBCS 官方资料、企业真实图表、流程工具官方示例 | 数据单位、比较目的、轴与标注、主线/异常/回环；架构图评审不能替代业务流程语义 |
| 插画、摄影与材质 | Behance、Pinterest、站酷、Dribbble、创作者作品集、Unsplash、Pexels | 主体/背景关系、构图、光线、材质、独立素材可用区域及原始作者 |
| UI 与网页交互 | 官方产品/设计系统、真实产品页面、Awwwards、Dribbble、Behance | 实际页面、响应式状态、导航、反馈与错误状态；宣传图不能证明可用性 |
| 动效与讲述 | 官方发布会/产品演示、公开演讲、设计工作室动效案例、相关视频平台原作者 | 播放具体片段，记录时间点、变化、触发、分组；静帧不能证明动画行为 |
| 可复用模板与源文件 | 用户指定的既有成品、Microsoft Create 等官方模板渠道、模板作者站、Slidesgo、PresentationGO、GitHub 模板仓库 | 实际文件格式、母版/主题/对象结构、字体、使用许可、免费导出限制与实际兼容性 |

## 检索与筛选

先按用途而非形容词搜索。例如中文管理层汇报可从“银行 业绩发布 演示 PDF”“annual results presentation”“editorial strategy deck”寻找结构，再用“warm architectural illustration”补素材方向。中文与英文、行业与跨行业、原生文件与视觉作品按缺口组合。无需把每一类固定绑定某个站点。

公开报告提供业务表达证据，作品集提供设计方法，模板提供可复用结构，视频提供运动证据，各自有适用边界。报告也可能排版差；热门设计也可能不适合高密度中文。

筛选时问：

1. 内容类型、密度、比例与受众是否相近？能解决哪一个具体问题？
2. 有没有真实内页或完整项目？封面不能证明长文和流程图表现。
3. 图表含义、异常路径和阅读顺序是否正确？是否依赖不可编辑贴图？
4. 来源是否能追溯到作者/机构？转载指向同一作品时合并记录。
5. 视觉学习和具体文件复用分别需要什么？许可未知的素材只作研究，不直接嵌入成品。

## 访问失败时

记录失败发生在哪一层：检索、页面打开、图片加载、登录或下载。更换检索词、公开原站或替代来源继续。不要对单一站点无界重试，也不要因为 Pinterest 受阻而停止整个研究。

参考的新旧以用途判断：当前产品操作、套餐、许可和模型能力需当次核验；经典排版原则可由较早作品提供证据。日期新不等于设计更合适。
