# 场景规范索引（全行业）

这份索引解决“先查什么”。每个 PPT 任务至少走一行，可跨多行。来源等级和规范卡模板见 [场景规范研究](design-research.md)。

下表是查找线索，不是每种 PPT 自动适用的义务。先判定用途、适用范围、强制性及版本；分别记录适用法律/监管/党内法规义务、主办方或用户要求、推荐标准与设计建议。GB/T、公文格式和 WCAG 不因列在表中就成为普遍硬要求。

## 1. 按场景查

| 场景 | 先查的依据与项目要求 | 落到 PPT 的检查点 |
|---|---|---|
| 党政机关公文、工作汇报 | GB/T 9704-2012《党政机关公文格式》；《党政机关公文处理工作条例》；主办单位 VI | 会议全称、单位名称、日期、落款、密级、标题/正文字体层级、版记 |
| 党校、党课、党建 | 《中国共产党党徽党旗条例》（2021）；党的文献权威原文；主办党校模板 | 政治表述逐字、引文版本、姓名职务、党徽标准素材与比例、配色要求（面积为设计建议） |
| 国企、事业单位 | 主办方 VI；上级单位公文/汇报模板；保密与信息公开规定 | 单位全称与简称、logo 版本、数据口径、可公开范围 |
| 上市公司业绩说明、路演 | 《证券法》；证监会《上市公司信息披露管理办法》；交易所公告与业绩说明会指引；公司 IR 模板 | 真实、准确、完整；风险提示；不无依据预测；财务口径与已披露一致；静默期 |
| 金融产品、银行保险 | 监管销售适当性、风险揭示与宣传材料管理规定；机构合规审稿 | 风险提示、收益表述、免责声明、审批编号、不得承诺保本保收益 |
| 医疗、医药、器械 | 《广告法》《医疗广告管理办法》；学会/医院/企业医学部模板；说明书 | 适应证范围、超适应证风险、免责声明、病例隐私、审批文号 |
| 学术答辩、科研汇报 | 学校研究生院/学位办模板与盲审规则；GB/T 7714-2015 参考文献；GB/T 15834-2011 标点；GB/T 15835-2011 数字用法 | 匿名要求、页数与时长、图表来源、引用格式、数据可复现 |
| 教学培训 | 学校/机构课程标准与模板；教室投影条件 | 学习目标、课时、讲义与投影一致、后排可读 |
| 产品发布、商业提案 | 品牌 VI、商标使用规范、《广告法》；客户模板 | 商标 ®/™、数据出处、绝对化用语、竞品表述、客户保密 |
| 政务公开、新闻发布会 | 政府信息公开规定、发布口径、保密审查 | 口径一致、数据可公开、字幕与口播一致 |
| 英文、国际会议 | 主办方 template；ISO 8601 日期；统一拼写体系；WCAG 2.1 对比度 | 术语表、时区、货币、日期格式、英式/美式不混用 |
| 展会、大屏、视频会议 | 场地技术参数：分辨率、比例、亮度、安全区、观看距离；主办方画面规范 | 16:9 还是 21:9、安全区、最小字号、字幕区、远端压缩后可读 |

党政/党校的完整字号、色彩与党徽规则见 [党政党校场景](party-government.md)。

## 2. 跨场景检查项（逐项判断适用性）

| 项目 | 依据 | 要求 |
|---|---|---|
| 文字对比度 | W3C WCAG 2.1 SC 1.4.3 / 1.4.11 | 作为可读性建议：正文 4.5:1，大字 3:1，必要图形 3:1；适用法规或项目采用时才按其范围作为要求，不能称所有 PPT 的法律下限 |
| 标点 | GB/T 15834-2011 | 中文标点全角、成对使用、不中英混排标点 |
| 数字 | GB/T 15835-2011 | 同一场景数字体例统一，单位与数值不拆行 |
| 参考文献 | GB/T 7714-2015 | 作者、题名、来源、年份、页码齐全 |
| 字体授权 | 字体厂商许可 | 商用字体需授权；交付前确认可嵌入或可替换，不静默回退 |
| 图片与肖像 | 著作权、肖像权 | 来源可查、授权可用；不用水印图、未授权人像 |
| 官方标识 | 党徽党旗条例、商标法、主办方 VI | 使用官方原文件，不重绘、不变形、不擅改配色 |

## 3. 判定“查到了”

- 打开原始页面或正式文件，记录条款号、章节或模板版本与日期。
- 搜索摘要、模板缩略图、二手教程只能当线索，不能当依据。
- 主办方正式模板的约束力高于通用经验；法规高于主办方模板。
- 适用的强制义务优先；其次遵守用户与主办方要求。推荐标准、设计方法和案例不能覆盖明确风格；确有项目要求冲突时指出具体条款与受影响对象。
- 检索未找到时写“截至某日，本次检索未找到适用的专用标准”，记录检索范围；设计经验标为建议，未知义务单列。不能由搜索无结果推断标准不存在，不自动为每条建议新增用户确认门。

## 4. 每个任务的输出

规范卡至少记录适用来源、义务/项目要求/设计建议的分类与未知项。新场景完整研究；局部任务在现有记录里复核受影响项和证据日期即可，来源仍有效无需重复联网。
