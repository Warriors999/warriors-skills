# 先图后稿：从确认预览到可编辑 PPT

仅用于用户明确选择“先看效果，确认后再做原生文件”的路线。已获授权的直接原生制作、局部改字与批准方向内返稿，不强制进入这条路线。

## 1. 两种产物与同一套素材

| 产物 | 用途 | 边界 |
|---|---|---|
| 视觉母版 V | 确认构图、配色、字体、图像与留白 | 优先以生产素材和真实原生排字合成预览；它本身不证明可编辑性 |
| 生产稿 P | 改字、改数、调对象、动画与交付 | 真文本、原生形状与独立图片，按目标编辑器验证 |

先确定源文案、背景、独立前景和原生对象，再制作预览；确认后复用同一素材和排版参数。默认不先生成整套整页图，再生成整套去字底图。用户明确要求整页模型概念稿时，说明文字为示意、后续需重建；源文案仍是生产依据，不用 OCR 定稿。正式预览用真实信息量，错字应修正，不能将错误默认为已批准内容。

## 2. 确认范围

1. 方向：制作约定的少量代表页，交给用户并等待明确同意；未回复、“我看看”与未反对都不是确认。修改后等待该阶段确认。
2. 整套：仅用户约定要先看整套再制作时设置。已有“按这个批量做”“不用逐页确认”或明确转原生文件的授权直接沿用，不新增整套或逐页门。
3. 记录确认版本与范围。批准方向内的改字、修错、批量延展直接执行；构图/配色/主体实质改变且超出授权时按约定重新确认。

为看版可以在内部以生产素材/原生排版合成预览，但在用户约定的确认完成前不把原生稿作为已批准的生产交付。用户只要图片时按范围交图即止，不自动转 PPTX。

## 3. 素材与生产

- 背景纸纹、复杂插画、照片、材质：独立背景素材。
- 标题、正文、引文、页码、简单线条、色块、表格与流程框：原生对象。
- 需要移动、改色或单独动画的前景：独立原始资产或透明素材。
- 官方标识优先复用合规原始文件，不送模型重绘。
- 只有整页图且无原始素材时才去字补全：保持比例、构图、光线与主体位置，去掉待重建对象，检查残字、涂抹、重复和漂移。已有干净底图直接复用。

目标软件按用户与项目确定，不固定为 WPS；共享设计契约覆盖执行技能的默认画布、字体、页码徽章与装饰。通常交付 `.pptx`，用户要 `.dps` 等格式时核实对应保存路径。真实字体、换行、单位、标点与锁定文案都要核对，不静默回退字体。

| 情况 | 路线 |
|---|---|
| 已有可编辑 PPT，只改文字/风格 | 在原稿中修改对象/母版，保留结构 |
| 已有干净素材与排版参数 | 复用素材，直接原生排版 |
| 文字多、准确性和编辑深度要求高 | 干净背景 + 原生文字/形状，或对象级重建 |
| 用户选择 WPS AI 图片转 PPT | 核实本机版本与权限，先试代表页，逐页校对 |
| 需要点击动画 | 原生对象与动画，检查初始隐藏和重影 |
| 只要背景 | 直接交真实底图，不创建整套 PPT |

## 4. WPS 与对象级重建的边界

WPS 普通图片导入通常是一图一页，文字仍在图片里；WPS AI 转换可能产出文本/形状，但版本、字体与复杂布局的效果须实际核实。按钮名称不证明可编辑性。

选择 editppt 时，先核实本次可用命令与安装状态，读取 `image-to-editable-ppt`，继承当前图片插件路由和设计契约。页面任务仅在明确授权且确需并行时委派，不把多页自动视为必须开 worker。没有原生通道时准确说明缺口，不能靠改扩展名或整页截图加浮层冒充完成。

## 5. 验收

按主技能的证据层级分别记录：

- 结构与内容：逐页提取原生文字，与源稿比对（标点不可忽略）；盘点文本/表格/形状/图片的真实编辑深度。
- 模拟预览：按清单另画的 Pillow 图片只证明模拟布局，不是 PPTX 实际渲染。
- 实际渲染：将真实 PPTX 经演示引擎渲染，与已确认预览并排看区域比例、字体换行、裁切、遮挡与颜色。视觉交付缺此证据时标“视觉验证未完成”，不称视觉验收通过。
- 目标编辑器：打开、保存、关闭重开，检查替换字体与修复提示；其他引擎渲染不证明目标软件兼容性。
- 放映：按用途检查初始状态、点击顺序、动画和播放。缺测项准确记录，不必为无动画任务测动画。

可用结构检查：

```bash
python3 <skill-root>/scripts/pptx-content-audit.py 生产稿.pptx --expected-text 源文案.json --output ./qa/content.json
python3 <skill-root>/scripts/slide-reference-audit.py compare 确认预览.png 实际渲染页.png --out ./qa
```

源文案 JSON 为 `{"slides":[{"text":"该页准确文字"}]}` 或 `{"slides":["该页准确文字"]}`；标点、空白与段落顺序须一致。字体清单只检查显式属性，继承未知项单列，不能证明字体安装或实际排版。图像对照不拉伸掩盖尺寸/比例问题；确需同纵横比分辨率归一化时显式加 `--normalize-resolution`。像素差受抗锯齿影响，不机械作为通过阈值。

## 6. 版本与交付

区分源文案、原始素材、确认预览和生产稿，避免覆盖可回退版本。说明实际检查的页数/对象和未完成项；未经真实渲染不要宣称视觉正确，未经目标软件验证不要宣称已在该软件重开通过。验收初次满足要求即可通过，不强制为流程制造一次返工。
