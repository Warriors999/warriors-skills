# 党政党校场景

适用于党校课件、党课、党建汇报、政企专题培训、主题党日等。核心是政治表述准确、层级清楚与投影可读。以下字体、配色和版式是默认设计建议，用户明确要求明亮红金、榜书或其他风格时可调整；实际适用的标识规定与项目要求另行核对。

## 1. 先分清硬规范与经验值

| 类型 | 依据 | 约束力 |
|---|---|---|
| 政治表述、引文、姓名职务、会议全称 | 权威原文、主办方审稿 | 硬性，必须逐字核对 |
| 党徽党旗 | 《中国共产党党徽党旗条例》（2021） | 核对实际用途适用条款及标准图案，保留准确形制；禁止用途按条款判定 |
| 字体调性 | GB/T 9704-2012《党政机关公文格式》 | 参考，不直接规定 PPT |
| 字号、留白、每页字数 | 投影可读性与场地经验 | 经验值，按屏幕和场地调整 |
| 主办方 VI | 本单位正式手册/模板 | 高于通用经验 |

GB/T 9704-2012 的要点：标题一般用 2 号小标宋体字，正文一般用 3 号仿宋体字，一级标题用黑体，二级标题用楷体。它约束的是公文，不是演示文稿；PPT 借用的是字体气质和层级关系，不能把“3 号仿宋”直接搬成投影正文。

## 2. 字体

优先级：主办方指定字体 > 系统可用且可嵌入的正式字体 > 下列替代。

| 角色 | 推荐 | 备注 |
|---|---|---|
| 封面/大标题 | 方正小标宋简体、思源宋体、宋体 | 默认庄重、笔画清楚；用户要求榜书/书法时按可读性、字体授权及项目要求选择 |
| 页标题 | 思源宋体 SemiBold、方正小标宋、黑体 | 与封面同气质，不混用三种字体 |
| 正文 | 思源黑体、微软雅黑、等线 | 默认避免细体；实际以场地可读性为准 |
| 引文 | 楷体、仿宋 | 与正文区分，但不做成花体 |
| 数字/英文 | Times New Roman 或同族字体 | 不与中文正文抢层级 |
| 注释/来源 | 与正文同族，常规体 | 参考下一节建议范围与场地测试 |

一套课件控制在 2 个字体家族（引文可加 1 个）。标题宋体 + 正文黑体是稳妥组合；不要标题宋体、正文楷体、数字手写体、英文装饰体混在一起。

## 3. 字号（16:9，1920×1080 或 13.333×7.5 英寸）

下列范围及“建议下限”均是经验值，不是法规；按既有画布、观看距离和投影效果选定。

| 层级 | 建议字号 | 建议下限 |
|---|---|---|
| 封面主标题 | 54–72pt | 44pt |
| 封面副标题 | 28–36pt | 24pt |
| 章节页标题 | 44–60pt | 36pt |
| 页标题 | 32–40pt | 28pt |
| 导语/金句 | 28–36pt | 24pt |
| 正文 | 24–28pt | 20pt（大场地不低于 24pt） |
| 引文 | 28–36pt | 24pt |
| 图表标签 | 16–20pt | 14pt |
| 来源/注释 | 14–16pt | 12pt |
| 页码 | 12–14pt | 10pt |

默认建议（不覆盖明确项目要求）：

- 先用场地和屏幕确认，再定字号；后排看不清就加字号或拆页，不靠加粗解决。
- 正文行距 1.25–1.5；标题 1.1–1.25。
- 中文每行 18–26 字，最多不超过 30 字。
- 每页 3–5 个信息点；超过 5 点优先拆页，不缩字号硬塞。
- 同一层级全篇只用一个字号，不逐页微调。

## 4. 色彩

用“角色”而不是“红色越多越党建”：

| 角色 | 参考色值 | 面积 |
|---|---|---|
| 主红 | `#9E1B22`、`#A61B29`、`#B01F24` | 正文页 15–25%，封面可到 35–40% |
| 深红 | `#7A1118` | 小面积压暗、标题底 |
| 金 | `#C8A45C`、`#D4AF6A` | ≤10%，只做线、编号、细装饰 |
| 暖白/纸色 | `#F7F1E6`、`#FAF6EE` | 55–70%，承担留白 |
| 墨色正文 | `#1F1F1F`、`#2B2B2B` | 正文与标题 |
| 次级灰 | `#6B6B6B` | 注释、来源 |

默认避免难以投影辨认的高饱和组合和过多特效；表中色值、面积和金色用途均为参考。用户明确要求亮红、红底、红金或立体标题时按该方向制作，重新检查层级、文字区及对比度，不以审美偏好禁止。

对比度可借鉴 WCAG：正文 4.5:1，大字 3:1；这是可读性建议，WCAG 不自动构成所有 PPT 的法律义务，法规/主办方采用时注明适用范围。红底白字要实测，深红底比正红底稳；金底黑字比金底白字稳。

## 5. 版式

- 画布：默认 16:9；先确认现场屏幕，超宽屏另设安全区。
- 外边距：不小于画布宽度的 5%（1920 宽约 96px）。
- 标题区：占高度 12–18%；正文从 18–22% 开始；页脚/页码留在底部 5% 内。
- 阅读路径：标题 → 正文（从左到右、从上到下）→ 结论。不要在一页里放两条互相竞争的主线。
- 正文默认左对齐；封面、章节、短引文可按已定构图居中，避免长段居中影响阅读。
- 网格：12 栏、24px 间距（1920 宽）、8px 基线；同类元素共用一套对齐线。
- 圆角默认 0–8px，以直角或微圆角为主；按用户参考与项目设计契约调整。
- 投影：弱或无；需要层次时用底色和留白，不靠重阴影。
- 装饰：全篇只保留一个母题（如一条金线、一个山形轮廓、一个编号样式），重复使用；不逐页换花样。

## 6. 图像与党徽

- 图像必须服务内容。没有语义关系的山河、长城、红绸、华表、飘带不默认加入。
- 全屏照片只在文字区有足够暗部/留白时使用；文字压在图上的，必须检查对比度和遮挡。
- 背景图优先做“安静底图”，文字和关键线条在 PPT 里原生排。
- 党徽优先使用官方标准素材，保持比例与配色，不用模型重绘。对旋转、阴影等处理及具体场景核对适用条例和主办方要求，不把所有审美建议伪称条例原文；不得用于条例禁止的商标、商业广告等用途。
- 党旗为红底金黄色党徽图案；不使用破损、污损、褪色或比例错误的素材。
- 不用带水印的模板图、来路不明的领导人照片、AI 生成的领导人形象。

## 7. 内容核对

交付前逐项核对：

- 引文是否逐字一致，来源、日期是否齐全。
- 领导人姓名、职务、排序是否正确。
- 会议、文件、活动名称是否用全称。
- 政策表述、口号、专有名词是否被改写。
- 数字、百分比、单位是否前后一致；图表与正文结论是否一致。
- “突出显示”“此处放图”等制作备注是否误入正文。
- 是否新增了原稿没有的政策观点、数据或引文。

涉及政治表述时，宁可保留原稿，也不做“润色式改写”。需要改写时只改语法和断行，不改语义。

## 8. 常见失败

- 把“党建风”做成红色素材堆叠：红绸、华表、天安门、光效全上。
- 每页硬塞一张风景图，正文被压到角落。
- 标题只是“讲政治”三个字，页面没有观点；可改成“讲政治是具体的，不是抽象的”（用户允许时）。
- 正文 14–16pt，投影后排看不清。
- 未经选择就添加金色立体字、玻璃卡片或荧光特效，与用户已定方向不符。
- 参考图明明是极简纸纹，成品却生成写实山水。

## 9. 验收清单

1. 项目指定比例正确（未指定时可用 16:9），标题区/正文区/页脚没有越界。
2. 投影后正文可读；字号符合项目约定和实际场地。
3. 色彩角色与面积符合已定方向，明亮红金或红底方案也须保证层级与可读性。
4. 标题、正文、引文层级清楚，字体组合符合项目契约；2–3 家族为默认建议。
5. 党徽/党旗素材形制准确、用途符合适用规定，不出现禁止的商业使用。
6. 引文、姓名职务、会议全称、数字逐项核对。
7. 装饰没有压字，文字安全区完整。
8. 风格与参考图的区域比例、色板占比、材质语言一致。

## 10. 参考依据

- 《党政机关公文格式》GB/T 9704-2012，国家标准全文公开系统。
- 《中国共产党党徽党旗条例》，2021 年，共产党员网/新华社发布。
- WCAG 2.1 Success Criterion 1.4.3 Contrast (Minimum)。
- Michael Alley, Assertion-Evidence approach（可选的内容结构方法，不强制改变用户原稿）。
