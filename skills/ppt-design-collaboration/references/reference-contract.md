# 参考契约

参考图不是一句“照着做”。先把“参考什么、不参考什么、参考到什么程度”写清楚，再开始设计或生成。

## 1. 先定角色

每张参考图至少标一个角色；同一张图可以承担多个角色，但要分别说明：

| 角色 | 允许拿走 | 不允许拿走 |
|---|---|---|
| 内容来源 | 文字、数据、结构、原稿事实 | 未经核对就改写政策表述 |
| 版式参考 | 区域比例、网格、对齐、层级、留白 | 具体品牌标识、水印、模板资产 |
| 风格参考 | 色彩角色、字体气质、材质、光线、装饰语言 | 把风格词当成具体画面 |
| 材质参考 | 纸纹、织物、金属、颗粒、笔触 | 把材质扩成整页插画 |
| 研究参考 | 方法、规范、案例证据 | 直接复制他人成品 |

## 2. 参考等级

先说是哪一级，避免“参考了”却不知道参考到什么程度：

| 等级 | 含义 | 典型用途 |
|---|---|---|
| L1 结构复刻 | 区域比例、网格、对齐、层级、留白位置基本一致 | 用户要“就按这个版式” |
| L2 风格迁移 | 色板、字体气质、材质、光线、装饰语言一致，结构可按内容重排 | 用户要“这个感觉，但内容不同” |
| L3 主题借势 | 只借一个母题或情绪，不保证结构/色板一致 | 用户只说“参考一下氛围” |

默认不要声称 L1 却只做到 L3。用户说“像这张”时，先说明本次按 L1 还是 L2 执行；不确定时按 L2 处理并写明，两者验收标准不同。

## 3. 权限声明

在设计方案开头写一句，让用户知道你在参考什么：

> 本次把图片1作为版式与配色主参考（结构复刻 + 风格迁移），图片2只提供纸纹材质；党校场景规范独立研究，不用参考图替代。图片3只用于研究，不进入成品。

如果用户说“只参考上传的”，从上下文确定范围，仅有影响结果的歧义时询问：

- 是“只参考它的视觉风格”，还是“连版式、内容结构也照它”？
- 是不再找**视觉**参考，还是连**规范**也不查？

用户限定视觉搜索时遵守；明确禁止任何外部检索时用现有依据复核，报告相关未知项，不扩搜。

## 4. 必填拆解表

不能只写形容词。每一项尽量给数字或可检查描述；无法测量的写“估计值”。

| 维度 | 要记录什么 |
|---|---|
| 画布 | 像素/比例、横竖、是否超宽屏 |
| 网格 | 分栏、边距、基线、内容区边界 |
| 区域 | 标题区、正文区、图像区、页脚各占多少高度/宽度 |
| 色板 | 主色/辅色/强调/底色的 HEX 与面积占比 |
| 字体 | 标题/正文/引文的字形气质、粗细、大小关系（不猜具体字体名） |
| 层级 | 第一眼、第二眼、第三眼看什么 |
| 装饰 | 色块、线条、纹理、徽标、图形的形状与位置 |
| 材质 | 纸纹/织物/金属/颗粒/笔触，强度与覆盖范围 |
| 光线 | 方向、软硬、对比、是否有投影 |
| 密度 | 每页信息块数量、文字行数、每行字数 |
| 留白 | 最大的连续安静区域及坐标 |
| 禁止复制 | 水印、品牌、人物肖像、模板资产、错误徽标 |

## 5. 形容词必须落地

每个形容词至少换成两个可检查参数，否则不许进入提示词：

| 说法 | 至少要变成 |
|---|---|
| 大气 | 大面积留白（占比）+ 大字号（pt）+ 低装饰密度 |
| 山河 | 剪影/写实/水墨？山体位置、占画面比例、颜色、是否有透视 |
| 红绸 | 织物质感还是纯色带？走向、面积、是否压字 |
| 高级 | 低饱和、窄色域、统一光源、材质克制，具体到色值和面积 |
| 简洁 | 信息块数量、装饰数量、留白比例 |

“山河大气”不能直接生成一张写实风景。用户参考如果是极简纸纹 + 山形剪影，就必须写成：暖白纸纹占 90%、底部 8–10% 红色低多边形山形剪影、无透视、无云海、无摄影细节。

## 6. 参考优先级

- 一个属性只设一个主参考，其他参考只能补充，不做 50/50 混合。
- 先遵守本任务实际适用的法律/监管/党内法规义务；再按用户指令、主办方要求、用户参考覆盖属性、研究参考、通用审美处理。推荐标准不自动是强制义务；用户与项目要求确有冲突时指出具体影响。
- 多张参考图时写清：图1 管结构，图2 管材质，图3 只管色彩；不要平均。
- 参考图之间风格冲突且用户没指定时，选与内容/场地最匹配的一张，说明放弃另一张的原因。

## 7. 参考进入生成的方式

需要图像模型复现参考时，先分清参考类型：

- **版式参考**：只提取区域比例、网格、层级和对齐，用原生形状/文本框重建。不要把整张参考图丢给模型“照着重画”，否则会复制文字、水印或错误徽标。
- **风格/材质参考**：把参考图作为参考输入（插件支持参考图/编辑时优先用参考图输入），不要只写文字描述。
- **内容参考**：只取文字/数据，视觉另行设计；不要连版式和装饰一起复制。

图像模型执行时：

1. 提示词写“保留 / 修改 / 禁止 / 输出”四段，保留项用比例、坐标、色值、材质描述。
2. 一轮只改一组相关变化；下一轮基于上一轮确认版本继续。
3. 优先从干净背景与独立前景开始，并复用同一生产素材合成预览；只有整页图且无原始素材时才去字补全。不要让模型顺便“丰富画面”。
4. 生成后按拆解表逐项对照，不按“感觉像不像”。

提示词骨架：

```text
用途与画布：16:9 党校课件正文背景，1920×1080。
保留：暖白纸纹占比约 90%；底部 8–10% 为暗红色低多边形山形剪影；
      无透视、无云海、无摄影细节；上部 60% 保持安静留白。
修改：只把底部山形剪影的起伏降低，其余不变。
禁止：新增建筑、人物、文字、徽标、水印、渐变光效。
输出：1920×1080 PNG，边缘干净，可直接作为文字底图。
```

## 8. 验收

先看结构，再看气质：

1. 画布比例、区域比例、标题区/正文区位置是否一致。
2. 主色/辅色/底色面积是否接近，是否多出参考里没有的色。
3. 装饰的形状、位置、数量是否一致；有没有新增“看起来更丰富”的元素。
4. 留白是否被填满；文字安全区是否被压。
5. 材质/光线是否从参考迁移，而不是换成另一种画风。
6. 有没有复制水印、品牌、人物或模板资产。

需要客观数据时运行：

```bash
python3 <skill-root>/scripts/slide-reference-audit.py audit 图片1.png 图片2.png --out ./reference-audit
```

输出包含画布、色板占比、横向/纵向色带、安静区网格和标注图。它只证明可测量的部分，字体名称、原生图层和动画顺序仍需另行核实。

需要比较“确认图”和“转换后渲染”时运行：

```bash
python3 <skill-root>/scripts/slide-reference-audit.py compare 确认图.png 渲染页.png --out ./qa
```

`mean_abs_difference` 和 `changed_pixel_pct` 是像素差，不是语义相似度；必须同时看并排图和分区差异，不能只看一个分数。

## 9. 失败信号

- 说“参考了”，但说不出参考图的具体比例、色值或区域。
- 参考图是极简风，成品却出现写实风景、复杂光影或额外装饰。
- 多张参考被平均成“四不像”。
- 只把参考图当文字描述，没有把图作为参考输入。
- 验收只说“氛围对了”，没有逐项对照。
